# 📝 Notes — Backend

> Серверная часть приложения для заметок с офлайн-синхронизацией между устройствами.

REST API на **ASP.NET Core**.


---

## ✨ Возможности

- **JWT-аутентификация** с парой токенов (access + refresh)
- **Дельта-синхронизация** — клиент запрашивает только изменения с момента последней синхры
- **Офлайн-режим** — работа без интернета
- **Мягкое удаление** — другие устройства узнают об удалении заметок
- **Полная документация** API в папке [`docs/`](./docs)

---

## 🛠 Стек технологий

| Слой | Технологии |
|------|-----------|
| Runtime | .NET 10, ASP.NET Core Web API |
| ORM | Entity Framework Core |
| База данных | PostgreSQL |
| Аутентификация | JWT |
