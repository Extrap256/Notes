# 07 — Соглашения

Короткий список правил, которые применяются ко всем эндпоинтам.

---

## Формат дат

Все даты — **ISO 8601**, **UTC**, с суффиксом `Z`.

Правильно: `2026-10-29T14:30:00Z`

Не использовать: локальное время, миллисекунды, смещение `+03:00`.

---

## Имена полей

Все поля в JSON — **camelCase**.

| Правильно | Неправильно |
|-----------|-------------|
| `createdAt` | `CreatedAt`, `created_at`, `CREATEDAT` |
| `isDeleted` | `IsDeleted`, `is_deleted` |

---

## Идентификаторы

Все `id` — строки в формате **UUID v4**.

Пример: `"a1b2c3d4-e5f6-7890-abcd-ef1234567890"`

Не использовать: числовые `id`, автоинкремент.

---

## Пагинация

Любой эндпоинт, возвращающий список, оборачивает результат:

~~~json
{
  "items": [],
  "totalCount": 0
}
~~~

| Поле | Тип | Описание |
|------|-----|----------|
| `items` | array | Массив элементов. Пустой массив `[]`, если ничего нет |
| `totalCount` | int | Общее количество элементов|

---

## Кодировка и Content-Type

Все запросы и ответы:

~~~
Content-Type: application/json; charset=utf-8
~~~

---

## Заголовок авторизации

Для всех эндпоинтов, кроме `/api/auth/*`:

~~~
Authorization: Bearer <accessToken>
~~~

Слово `Bearer`, пробел, токен. Без кавычек.

---

## Версионирование

При изменении контракта сервер обновляет документацию
и указывает дату в `Changelog` каждого файла.

Клиент и сервер должны быть согласованы по версии контракта.
Если сервер меняет формат ответа — клиент должен быть обновлён.
